# Security

Overscope runs entirely on your machine. It makes no network calls, invokes git with
read-only commands, and never writes to your working tree. It only reads coding-agent
transcripts you already have on disk.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through
GitHub's [security advisories](https://github.com/sandeepwastaken/overscope/security/advisories/new),
and you'll get a response as soon as possible.
